Floats

A float is a box that is shifted to the left or right on the current line, allowing text and inline content to wrap around it. Floats are a core part of the classic box layout model and are used extensively in encyclopedia articles for images and sidebars.

The float is taken out of the normal flow and shifted to the left or right until its outer edge touches the containing block's edge or another float's margin box. Line boxes beside the float are shortened so content wraps around it.

Tables

CSS tables build a grid of rows and columns from table display types. Cells can span multiple columns (colspan) or rows (rowspan), and borders can be separate or collapsed.

Sticky positioning

A sticky box is laid out in flow like a relatively positioned box, but is offset relative to its nearest scroll container based on the scroll position. Sticky headers remain visible while the page scrolls, which is essential for long articles.
