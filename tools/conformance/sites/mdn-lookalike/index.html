Classic box layout

The CSS box model describes the rectangular boxes that are generated for elements in the document tree and laid out according to the visual formatting model. Each box has a content area, optional padding, a border, and a margin.

Floats

A float is a positioned box that is shifted to the left or right within its containing block. Content flows along the side of the float, wrapping around its margin box.

.figure { float: right; width: 200px; margin: 0 0 1em 1em; }

Clear

The clear property specifies whether an element can be next to floating elements that precede it or must be moved down below them.
