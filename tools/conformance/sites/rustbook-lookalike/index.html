Classic box layout

In this chapter

  • Floats and clearing
  • CSS tables
  • Sticky positioning

The classic box layout model is the foundation of most of the web. It is built on the CSS box model: every element generates a rectangular box with content, padding, border, and margin areas.

Floats and clearing

A float is a box that is taken out of the normal flow and shifted to the left or right. Content flows around it, wrapping along its margin box. The clear property moves an element below earlier floats.

float: left; clear: both;

CSS tables

CSS tables build a row-and-column grid from table display types. Cells may span columns (colspan) or rows (rowspan), and borders may be separate or collapsed.

Sticky positioning

A sticky box is positioned in flow like a relatively positioned box, but is offset based on the scroll position of its nearest scroll container. Sticky headers remain visible while the page scrolls.
