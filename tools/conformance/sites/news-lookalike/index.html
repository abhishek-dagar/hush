Classic box layout is back

Most of the web is still built on floats, relative and absolute positioning, overflow scrolling, and tables. This page exercises the parts of the engine that spec 0009 brings to baseline: figures that float beside the text, a header that sticks while you scroll, and a table that lays out like Chrome.

When an image is floated, line boxes beside it shorten so the text wraps around the float's margin box, and a line whose content cannot fit beside the floats moves down until it fits or the floats end. That is CSS 2.2 section 9.5.1, rules 1 to 9.

The header above uses position: sticky with top: 0, so it stays at the top of the scrollport while the article scrolls, but never leaves its containing block. The sidebar beside it is sticky too, offset from the top once scrolling passes it.

Floats, clear, and formatting contexts

A clear: both block moves below the earlier floats in its block formatting context, and a BFC root with height: auto grows to hold its floats. These are the rules that keep news and documentation pages readable.

This paragraph sits below the cleared floats and runs full width again, just as it would in Chrome.
